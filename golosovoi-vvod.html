Как пользоваться голосовым вводом на Windows и Mac

Бесплатные инструменты, которые превращают вашу речь в текст прямо в любом приложении – без переключения между окнами.

Windows

Lispr – для Windows

Голосовой ввод с переводом на лету · Whisper large-v3

  • бесплатно (ранний доступ)
  • без аккаунта
  • ~8 МБ
  • 99 языков
Скачать Lispr↗

Установка

  1. Зайти на lispr.ai/ru/windows и нажать «Скачать» (установщик ~8 МБ, Windows 10+ 64-bit).
  2. Запустить установщик – Lispr подписан через Microsoft Azure Trusted Signing, издатель Codebridge Technology, Inc., так что SmartScreen не должен ругаться.
  3. При первом запуске разрешить доступ к микрофону.
  4. Готово – иконка Lispr появится в системном трее.

Как пользоваться

  1. Поставить курсор в любое текстовое поле – Slack, Notes, Figma, терминал, что угодно.
  2. Зажать правый Ctrl и говорить на своем языке – текст напечатается ровно то, что сказали.
  3. Чтобы сразу перевести фразу – во время речи дополнительно зажать Shift (получится Ctrl + Shift): текст ляжет на целевом языке.
  4. Отпустить клавиши – готово, без copy-paste и переключения окон.

Работает только с интернетом (расшифровка идет в облаке, поэтому и быстро – около 200 мс). Понимает ~99 языков, переводит на 32 – два основных целевых языка закрепляются на клавишах-слотах в настройках.

Mac

Lispr – для Mac

Голосовой ввод с переводом на лету · Whisper large-v3

  • бесплатно (ранний доступ)
  • без аккаунта
  • ~4 МБ
  • 99 языков
Скачать Lispr для Mac↗

Установка

  1. Зайти на lispr.ai/ru и нажать «Скачать» (файл ~4 МБ, macOS 11 Big Sur+, Apple Silicon и Intel).
  2. Открыть скачанный .dmg и перетащить Lispr в Applications.
  3. Запустить приложение – сборка нотаризована Apple, поэтому macOS открывает ее без предупреждений о безопасности.
  4. Разрешить два доступа в Системных настройках, когда попросит: «Микрофон» и «Универсальный доступ» (нужен, чтобы Lispr мог печатать в других приложениях).
  5. Готово – иконка Lispr появится в строке меню.

Как пользоваться

  1. Поставить курсор в любое текстовое поле – Slack, Notes, Figma, терминал, что угодно.
  2. Зажать правый Option (⌥) и говорить на своем языке – текст напечатается ровно то, что сказали.
  3. Чтобы сразу перевести фразу – во время речи дополнительно зажать Control (⌃): текст ляжет на целевом языке.
  4. Отпустить клавиши – готово, без copy-paste и переключения окон.

Работает только с интернетом (расшифровка в облаке, полный цикл – около 200 мс). Понимает ~99 языков, переводит на 32 – два основных целевых языка закрепляются на клавишах-слотах в настройках.

Mac

Wispr Flow – для Mac

AI-диктовка · Редактирование текста голосом

  • macOS 12+
  • форматирует текст сам
  • command mode
Скачать Wispr Flow↗

Установка

  1. Скачать приложение на wisprflow.ai/get-started – выбрать версию под свой Mac (Apple Silicon или Intel).
  2. Открыть скачанный файл .dmg.
  3. Перетащить иконку Wispr Flow в папку Applications.
  4. Запустить Wispr Flow из Applications или через Spotlight (⌘ + Пробел → «Wispr Flow»).
  5. Разрешить доступ к микрофону, когда macOS спросит.
  6. Войти в аккаунт или начать пробный период – это займет пару минут.

Как пользоваться

  1. Иконка Wispr Flow появится в строке меню сверху экрана.
  2. По умолчанию активация – двойное нажатие Fn (можно изменить в настройках).
  3. Зажать горячую клавишу в любом приложении и начать говорить.
  4. Текст появится отформатированным и без лишних слов-паразитов.

Command Mode: выделите текст и скажите, например, «Сделай это более формальным» или «Преврати в список» – Wispr Flow отредактирует текст голосом.

Windows

Handy – для Windows (альтернатива)

Бесплатно · Open source · Работает офлайн

  • если нужен офлайн
  • без подписки
  • без лимитов
  • голос не уходит в облако
Скачать Handy↗

Установка

  1. Открыть handy.computer/download и скачать установщик для Windows (~12,6 МБ).
  2. Запустить установщик и пройти шаги мастера установки.
  3. Готово – иконка Handy появится в системном трее.

Для тех, кто предпочитает командную строку:

winget install cjpais.Handy

Как пользоваться

  1. Запустить Handy – иконка появится в трее (рядом с часами).
  2. Поставить курсор в текстовое поле – Word, браузер, мессенджер, что угодно.
  3. Нажать горячую клавишу, чтобы начать запись (настраивается в приложении).
  4. Просто говорить – текст сам появится в поле.
  5. Нажать ту же клавишу еще раз, чтобы остановить запись.

Язык распознавания, горячие клавиши и модель – все это меняется в настройках Handy через иконку в трее.
